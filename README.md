A project to learn how to use API calls.

## Movie browser
An application to browse for movies.

### Features
- Search for movies and shows through a search bar
    - All movies display their image, and fallback image is provided
- Click on movies to display more details
- View a movie's episodes and seasons, and click on it to open TVMaze episode page.

### Things I planned but didn't do
- Filter by genre
    - The API didn't seem to provide anything for this, so I didn't bother too much with it
- Responsive UI
    - Responsive UI takes a long time to make and would've taken a lot of time testing.
